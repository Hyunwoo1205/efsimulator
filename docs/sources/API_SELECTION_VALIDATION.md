## 현재 접근 거부의 진단 범위

과거 성공했던 정상 요청 `GET https://efhub.com/api/public/packs?search=&page=1&limit=30`은 **15:23:58 UTC**에403·17bytes·본문 `error code: 1010`이었다. 헤더/파라미터를 바꾸거나 추가 요청하지 않았다. 공개문서 `/privacy`도 별도의403이었다.

[Cloudflare 공식1010 설명](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1010/)에 따르면 이 오류 코드는 브라우저 서명에 대한 사이트 보안 설정의 거부와 관련된다. 현재 본문은 이 설명에 부합하지만 구체적인 차단 규칙/대상 범위·특정 헤더·실제 응답 계층을 확정하지 않는다. 과거 본문 없는 players403의 원인으로 소급하지 않는다.

보존된 헤더는 allowlist 일부뿐이다. `cf-error-type`, `cf-error-origin`, Ray ID는 **미보존**이며 실제 헤더가 없었다는 뜻이 아니다. 이를 얻기 위해 거부 요청을 재시도하지 않았다. 향후 허용된 진단에서는 [공식 오류 헤더](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-error-headers/)도 비밀 제외 allowlist로 보존한다.
