1. **T044 완료 → T017-A 규칙·계약:** API drawOptions의 단일100/10회900 고정 가격·지원수량과 한 팩 이상 정확한 회차·N/S/A·사용자 비복원/리셋 정책을 연결한다. T044데이터준비를소비하고최신첨부9장/사용자지시의UX·세션계약으로실행한다. ready를엔진/저장완료로표시하지않는다. 기본 가격에 추가 조사 게이트를 두지 않으며 다른 미확인 모드는 구분한다.
2. **T017-B/C 엔진·저장:** 균등 비복원 확인 모드의 순수 엔진·익명 일반을 구현한 뒤 IndexedDB 단일 트랜잭션·revision·commandId로 저장/복구한다. 다른 팩의 publication 변경으로 진행을 초기화하지 않는다.
3. **T017-D/E 화면·2D:** 판매 중/종료 체험 섹션을 분리하고 개별관찰한정지화면과사용자확정흐름으로기존서버·카드·정렬을재사용해추첨/잔여/획득내역·확정결과/건너뛰기·접근성을연결한다. 사진에서관찰하지않은3D시간/순서를재현했다고하지않는다.
4. **T017-F 검토 배포:** 경계/동시 실행/복구/갱신·종료와 모바일을 검증하고 현재public인같은실제앱의audience를유지해배포한다. snapshot QA와 hosted 직접 UI 검증을 구분하며 GitHub 내용·실제 CI까지 확인한다.
5. **T018 3D:** 사용자 APK 업로드 후 개봉 자료를 분석하고 검증한 엔진·세션의 결과를 재생하는 3D·모바일 성능·자산/비용·2D 대체를 검증한다. 공개 전환·main 병합·호스팅 이전은 자동 수행하지 않는다.
