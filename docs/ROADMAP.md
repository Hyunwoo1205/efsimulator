## 다음 실행 순서

1. **T017-A 규칙·계약:** 한 팩 이상 정확한 회차·N/S/A·사용자 비복원/리셋 정책과 실제 단일/다회/가격 근거·판매/종료 체험의 근거 연결을 정리하고 준비 판정·UX·세션 계약을 만든다. 미확인 모드는 잠그고 비용만 미확인이면 표시를 보류한다.
2. **T017-B/C 엔진·저장:** 균등 비복원 확인 모드의 순수 엔진·익명 일반을 구현한 뒤 IndexedDB 단일 트랜잭션·revision·commandId로 저장/복구한다. 다른 팩의 publication 변경으로 진행을 초기화하지 않는다.
3. **T017-D/E 화면·2D:** 판매 중/종료 체험 섹션을 분리하고 실제 관찰한 공개 흐름에 맞춰 기존 서버·카드·정렬을 재사용해 추첨/잔여/획득 내역과 확정 결과 재생·건너뛰기·접근성을 연결한다.
4. **T017-F 검토 배포:** 경계/동시 실행/복구/갱신·종료와 모바일을 검증하고 같은 private 앱에 배포한다. snapshot QA와 hosted 직접 UI 검증을 구분하며 GitHub 내용·실제 CI까지 확인한다.
5. **T018 3D:** 사용자 APK 업로드 후 개봉 자료를 분석하고 검증한 엔진·세션의 결과를 재생하는 3D·모바일 성능·자산/비용·2D 대체를 검증한다. 공개 전환·main 병합·호스팅 이전은 자동 수행하지 않는다.
