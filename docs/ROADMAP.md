# efsimulator 개발 로드맵

최신 사용자 결정은 **전체 누적 DB/API**와 **현재 판매 선수팩을 위한 사이트 DB/배포 스냅샷**을 분리한다. 이전의 “확률표 대상만 수집”은 사이트층에 한정되며, 전체 누적층은 EFHub에서 정상 확보 가능한 모든 players/packs로 확대한다. 기존 엔티티는 삭제하지 않고 변경을 개정 이력으로 보존한다. 실제 새 DB/API는 아직 만들지 않았다.

## 두 계층의 범위

| 구분 | 전체 누적 DB/API | 사이트 DB/배포 스냅샷 |
| --- | --- | --- |
| 모수 | EFHub에서 정상 확보 가능한 모든 선수 카드/선수팩. 출처가 실제 제공하는 범위를 기록 | 공식 한국어 확률표의 최신 정상 목록·종료 UTC·신선도가 확인된 현재 유효 팩과 해당 카드 |
| 보존 | 새 원본 ID 추가, 기존 엔티티 무삭제. 원문/관측/변경 revision 보존 | 활성 대상은 추가·수정·판매 종료/검증 상태에 따라 제외. 전체 누적층과 과거 발행본은 보존 |
| Standard/과거 | 원문에 있으면 보존. 전역 전수 확보 성공 여부는 별도 보고 | 모든 특수 완전성 확인 후 N−S를 익명 Standard 그룹으로 표현. 실명 Standard 상세는 필수 아님 |
| 감독·고정 팩 | players/packs 원문 중첩값은 변형 없이 보존하되 별도 감독 수집/활성 연결은 지원하지 않음 | 감독 일괄 제외. 구매 즉시 일괄 획득 팩은 개봉 시뮬레이터 제외 |
| API | 별도 폴더/저장소/서버는 실제 요구와 비용 확인 후 결정. 원문/권한 비공개 경계 유지 | 전체층의 검증된 버전에서 추출. 초기 정적 JSON과 후속 동적 API 구분 |

공식 기준은 https://efootball-web.konami.net/probability_kr.php 이다. 관측 7개를 상수로 쓰지 않는다. 2026-10-25 관측의 Midfielders 종료는 **2026-10-26 10:59:59 KST**로 이번 점검 시점에 이미 지났다. 현재 공식 페이지는 재요청하지 않았으므로 당시 7개를 현재 판매 목록으로 복제하지 않는다. 표 미기재 가격·재화·무료·다회·리셋 규칙은 미확인으로 둔다.

## 현재 실행 순서

1. 최신 GitHub work를 기존 대상 Work에서 읽고 현재 HEAD/사용자 변경과 비교한다. 승인된 정상 push의 실제 원격 SHA/CI를 확인하며 bundle은 선택 백업이다. main만 읽으면 앱/최신 계획이 없다.
2. T021에서 부모 환경이 검증한 Library v1의 SHA/행/ID 결과를 재사용하고 기존 대상 Work의 수집 로그/페이지 체크포인트/완료 기록과 대조한다. 50,840과의 3,443 차이는사용자 설명상 중복 제거 결과로 기록하고 원본 중복 제거 로그 재검증 한계만 유지한다. 누락 의심으로 막거나 전체 재수집하지 않는다. 이미 합쳐진 배열이면 기존 페이지 병합 도구에 직접 넣지 않는다. 원본 페이지/메타가 없으면 2119/50840과의 완전성을 증명하지 못했다고 기록한다. 대상 Work의 packs 수집 준비를 기존 출력/체크포인트부터 이어받고 새 채팅·중복 수집을 만들지 않는다. raw 완료와 상세 관계는 별도다. 별도 Sites 초기 페이지/소스/번들은 의도적으로 이관 제외한다.
3. T010→T011: 정상 제공 자료를 재사용해 전체 누적 수입·개정/매핑을 설계/구현하고, 최신 공식 대상만 별도 materialize한다. 미확인 필드/관계·이미지·권리를 검증한 한 팩 표본을 만든다.
4. T012→T013: 실제 Pages 설정과 본 앱 소스 위치를 확인해 검토 URL을 제시하고 사용자 검토·운영 반영 승인을 구분한다. 이번 승인은 work 정상 푸시와 기존 CI·preview 확인에 한정한다. main 병합과 배포 설정 변경은 하지 않는다.
5. T014→T015→T016: 누적 확보 범위와 현행 완전성을 각각 완성/보고하고 두 갱신 파이프라인·자체 API/백업/복구를 검증한다. 누적층에는 물리 삭제를 전파하지 않는다.
6. T017→T018: 검증된 규칙의 시뮬레이터와 익명 Standard 연출, 이후 3D. 용량/모바일 실측 뒤 Cloudflare 자산 분리/OCI를 비교한다.
